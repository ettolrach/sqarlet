# sqarlet

sqarlet is a compiler for the SQA Reference Language, also known as Haggis.

This project is currently in the very early stages of development. I am working on the typechecker and am using that to disambiguate the issues in the spec. There is no parser or code generator at the moment.

The specification is available [from the SQA website](https://www.sqa.org.uk/sqa/files_ccc/Reference-language-for-Computing-Science-Sep2016.pdf).
